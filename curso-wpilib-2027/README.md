# Stardust Academy — WPILib 2027 Alpha 7

Curso interativo, em um único arquivo HTML, para planejar e desenvolver o robô FRC 2027 em Java e simulação.

## Como abrir

1. Baixe `index.html`.
2. Abra o arquivo em qualquer navegador moderno.
3. O progresso fica salvo localmente no navegador por meio de `localStorage`.

Não há build, servidor, dependências NPM ou conexão obrigatória com a internet.

## Conteúdo

- 11 unidades e 44 missões;
- XP, vidas, sequência e desbloqueio progressivo;
- quizzes e desafios de código;
- laboratórios para AdvantageScope;
- migração WPILib 2026 → 2027 Alpha 7;
- Telemetry, Tunables e Selectable;
- Commands v3 e OpModes;
- swerve, localização, Limelight, intake e indexer;
- elevador, manipulador, shooter, Superstructure e climb;
- PathPlanner e partida completa simulada.
